
# Servicio de Pizzas 

Proyecto en Node.js con Express que expone rutas para probar en Postman:

- GET /api/saludos → mensaje de saludo
- GET /api/v1/pizzas → lista de pizzas
- GET /api/v1/tamanios → lista de tamaños
- GET /api/v1/bebidas → lista de bebidas

## Cómo probar
probar cada link del host propio:
http://localhost:3000/api/saludos
http://localhost:3000/api/v1/pizzas
http://localhost:3000/api/v1/tamanios
http://localhost:3000/api/v1/bebidas
cada uno probarlo en el get del postman
